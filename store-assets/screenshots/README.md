# Screenshot capture guide

Chrome Web Store screenshots must show the real extension experience. Save PNG files at exactly 1280×800 with square corners and no decorative padding.

Recommended captures:

1. `01-overview-1280x800.png` — dashboard overview with summary cards and charts
2. `02-market-analysis-1280x800.png` — trade summary, estimated profit, and transaction details
3. `03-tech-tree-1280x800.png` — localized technology tree and research queue
4. `04-debris-1280x800.png` — debris recovery totals, charts, and recent recovery details

Before capture:

- use the latest unpacked/store-ready build
- select NX-NF or NX-S0 and synchronize once
- close notifications and confirmation dialogs
- avoid showing reviewer credentials, private messages, session identifiers, or account details that should not be public
- if a player name or resource balance is sensitive, use a dedicated low-value review account

The checked-in screenshots were captured manually from the extension, normalized to 1280×800, and scrubbed of the stale build badge. Player names in the market-analysis screenshot are replaced with `已隐藏`; the underlying transaction values are unchanged.

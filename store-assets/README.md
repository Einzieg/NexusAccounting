# Chrome Web Store assets

Files in this directory are uploaded separately in the Chrome Web Store developer dashboard; they are not included in the extension ZIP.

- `icon-128.png`: store icon, 128×128
- `small-promo-440x280.png`: required promotional tile
- `marquee-1400x560.png`: optional marquee image
- `screenshots/*.png`: real product screenshots, 1280×800
- `source/promo-generated.png`: original generated promotional artwork
- `source/promo-prompt.md`: reproducible ImageGen prompt

Do not publish screenshots containing reviewer credentials, session identifiers, private messages, or other sensitive account information.
